# BURTC: a backup counter against SYSRTC, and a control that takes the clock away

Date: 2026-11-27. Item 5 of `_tmp/night/STATE-NIGHT2.md` (queue: "BURTC / contador de backup"). Board: XIAO MG24 Sense
(EFR32MG24B220F1536IM48-B) on the bench at `lnx`, CMSIS-DAP probe. Example: `crates/efr32mg2x-hal/examples/hal_burtc_backup.rs`;
driver: `crates/efr32mg2x-hal/src/burtc/mod.rs`; hand-out: `Board::burtc`.

## The record

Four flashes, four boots, `status=PASS` in all four. Three of the records are identical except in the last digit of the
deltas; nothing else moves:

```
burtc: ok=1 run=1 pre=0 d0=32901 s0=32901 r0=1000 pd=3 d1=4113 s1=32901 r1=125 ctl=0 cs=32902 bk=16448 bs=16451 rb=999 if=0x00000000 st=0x00000001 sb=0x00000000 ck=0x00000101
burtc: ok=1 run=1 pre=0 d0=32900 s0=32900 r0=1000 pd=3 d1=4112 s1=32899 r1=124 ctl=0 cs=32899 bk=16446 bs=16450 rb=999 if=0x00000000 st=0x00000001 sb=0x00000000 ck=0x00000101
burtc: ok=1 run=1 pre=0 d0=32901 s0=32901 r0=1000 pd=3 d1=4112 s1=32900 r1=124 ctl=0 cs=32900 bk=16448 bs=16451 rb=999 if=0x00000000 st=0x00000001 sb=0x00000000 ck=0x00000101
burtc: ok=1 run=1 pre=0 d0=32899 s0=32899 r0=1000 pd=3 d1=4113 s1=32900 r1=125 ctl=0 cs=32901 bk=16447 bs=16451 rb=999 if=0x00000000 st=0x00000001 sb=0x00000000 ck=0x00000101
```

Fields: `d0`/`s0` are the `BURTC` and `SYSRTC` deltas over a 1000 ms window at prescaler 0, `r0` their ratio in ticks
per thousand; `pd` is `CFG.CNTPRESC` read back after `set_prescaler(3)`; `d1`/`s1`/`r1` the same window at divide by 8;
`ctl`/`cs` the counter and `SYSRTC` deltas with `EM4GRPACLK` pointed at nothing; `bk`/`bs`/`rb` the 500 ms window after
the source came back; `if` the interrupt flags; `st` `STATUS` (bit 0 running, bit 1 configuration locked); `sb`
`SYNCBUSY`; `ck` `clock_readback` -- bit 0 `CMU_CLKEN0.BURTC`, bits 8..11 `EM4GRPACLKCTRL.CLKSEL`.

## What each run rules out

1. **Prescaler 0.** `d0 == s0` to the tick in three of four boots and within one tick in the other. A counter running at
   half rate, at 2x, or not at all does not land on 32900 in a window `SYSRTC` also measured at 32900.
2. **Prescaler 3 (divide by 8).** `d1` is 4112-4113 where `s1` is 32899-32901: 124-125 per mille. The prescaler is a
   real divider, not a field that is written and ignored -- and `pd=3` says the write landed.
3. **Control, source removed.** `ctl=0` while `cs` is still ~32900: with `EM4GRPACLKCTRL.CLKSEL = 0` and nothing else
   touched, the counter stops dead and the reference keeps counting. Without this run, "the counter advanced" would not
   distinguish a clocked counter from a register that reads what it last held.
4. **Source restored.** `bk=16446..16448` in 500 ms, ratio 999. The counter resumes, so the control in run 3 was the
   clock and not a block that had stopped for ever.

`ck=0x00000101` in every boot: the bus gate is set and `CLKSEL = 1` (LFRCO) at the end of the record. `if=0` -- nothing
armed, nothing latched; `sb=0` -- no domain crossing was left in flight.

## Two facts paid for with a fault

1. **The backup domain outlives a core reset.** The first boot of this driver died with a precise bus fault at
   `BURTC_NS + 0x08` (`CFSR=0x8200`, `HFSR=0x40000000`, `BFAR=0x50064008`, `pc=0x08007e5e`): `CFG` is not writable while
   `EN` is set, and the image flashed before it had left `EN` set -- the reset that the flash tool performs does not
   clear the backup domain. `new` now reads the state and drops `EN` (waiting out `EN.DISABLING`) before writing `CFG`.
2. **`CMD` is not writable with `EN` low.** The next attempt faulted at `BURTC_NS + 0x0c`
   (`BFAR=0x5006400c`): `CMD.STOP` after the enable was dropped. The order the part wants is stop (while enabled) ->
   drop `EN` -> write `CFG` -> set `EN` -> `CMD.START`. `stop`, `disable` and `enable` in the driver are each a no-op when
   the block is already in the requested state, so neither write is issued where it would fault.

## What this does not prove

- **Not an absolute frequency.** Two counters on one LFRCO agreeing says `BURTC` counts at the branch's rate; it says
  nothing about how accurate LFRCO is. A crystal (LFXO) or a precision-mode measurement would be a different record.
- **Not EM4.** The counter is read in EM0. Retention of `CNT` across EM4 entry and exit is `emu`'s subject and has no
  instrument here.
- **Not the compare/overflow path.** `COMPTOP` is left clear and the interrupt is not armed; `IF` is read only.
- **Not the prescaler's phase.** `set_prescaler` cycles `EN`, and the tick in flight when the window opens is neither
  the old period nor the new one; the record measures a full second after the change, so the phase is not visible.
